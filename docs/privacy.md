# 개인정보 처리 안내 (초안)

앱의 '개인정보 처리 안내' 화면(`apps/web/src/ui/PrivacyNotice.tsx`)과 같은 내용이다. 학교 개인정보 보호책임자가 반곡고등학교 개인정보 처리방침과 맞춰 확정한 뒤, 두 곳을 함께 고친다.

## 1. 처리 목적

- 반곡고등학교 Google 계정인지 확인하고 로그인시키기 위해
- 크롬북에서 문서를 열고 저장하는 기능을 제공하기 위해
- 오류를 찾고 서비스를 개선하기 위해 (개인을 알아볼 수 없는 통계)

## 2. 처리하는 정보

| 정보 | 저장 위치 | 보관 기간 |
|---|---|---|
| 이름, 학교 이메일, 프로필 사진 (화면 표시용) | 사용하는 크롬북 브라우저 | 브라우저 탭을 닫을 때까지 |
| 자동 임시 저장 문서 | 사용하는 크롬북 브라우저 | 7일, 로그아웃 때 삭제 선택 가능 |
| 최근 문서 목록 (Drive 파일 이름과 ID) | 사용하는 크롬북 브라우저 | 목록·브라우저 데이터를 지울 때까지 |
| Google 계정 고유번호, 역할, 최근 접속 시각 ¹ | 학교 운영 서버 (Google Cloud Firestore) | 마지막 접속 후 1년 (Firestore TTL 자동 삭제) |
| 오류 코드, 앱·브라우저 버전, 파일 형식과 크기 구간 ¹ (사용자 식별 정보 없음) | 학교 운영 서버 | 90일 (Firestore TTL) |
| 접속 기록 (IP 주소, 브라우저 정보) ¹ | Google Cloud 로그 | 30일 |

¹ 학교가 운영 서버(백엔드)를 켠 경우에만 처리한다.

문서 내용과 파일 이름은 학교 서버로 보내지 않는다. 문서는 크롬북 안에서 처리되고, 사용자가 고른 크롬북 폴더나 본인의 Google Drive 에만 저장된다.

## 3. Google Drive 접근 범위

drive.file 권한만 쓴다. 사용자가 직접 고른 파일과 이 앱으로 만든 파일에만 접근하며, Drive 의 다른 파일 목록이나 내용은 볼 수 없다. Google 에서 받은 정보는 Google API 서비스 사용자 데이터 정책(제한적 사용 요건 포함)에 따라 문서 편집 기능에만 사용한다.

## 4. 제3자 제공과 처리 위탁

- 제3자 제공: 없음
- 처리 위탁: Google LLC — Google Workspace for Education(로그인, Drive), Google Cloud·Firebase(웹 호스팅, 운영 서버). 일부 처리는 국외에서 이루어질 수 있다.

## 5. 정보주체의 권리

학생·보호자·교직원은 개인정보 열람·정정·삭제·처리정지를 요청할 수 있다. 크롬북에 남은 정보는 로그아웃 때 직접 지울 수 있다. 서버의 사용자 기록을 바로 지워 달라는 요청은 요청자의 Google 계정 고유번호(sub)로 Firestore `users/{sub}` 문서를 지운다 (docs/operations.md).

## 6. 문의

반곡고등학교 정보부. 개인정보 보호책임자는 반곡고등학교 개인정보 처리방침을 따른다.

## 확정 전 확인할 것

- [ ] 학교 개인정보 처리방침의 위탁 항목에 Google Cloud(Firebase Hosting, Cloud Run, Firestore) 추가
- [ ] 보호자 안내·동의 필요 여부 (Google 18세 미만 앱 접근 정책, docs/legal-review.md 6절)
- [ ] 보관 기간(90일, 30일)이 학교 기록 관리 기준과 맞는지
